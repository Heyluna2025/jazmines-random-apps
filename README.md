# Jazmine's random apps

Small apps built for talks, workshops and experiments. Each one lives in its own folder with its own README.

| App | What it is |
| --- | --- |
| [your-future-starts-here](your-future-starts-here/) | Audience participation app for the talk *AI and the Future of Work* — students join by QR code, answer a poll, vote on an app feature, and build a one-card project idea. Audience, presenter and projector views on one live session. |
| [ai-challenge-landing](ai-challenge-landing/) | Single-file registration page template for a free 5-day live challenge funnel (hero + VSL, countdown, curriculum, hosts, FAQ, modal form that carries UTMs through). |
